## 2. Network & Power

| Requirement | Specification | Notes |
|---|---|---|
| **WiFi Network** | Standard 802.11b/g/n (2.4 GHz) | ESP32 connects via WiFi to same network as laptop running Mosquitto broker |
| **MQTT Broker** | Mosquitto (Docker, localhost:8883) | Runs on laptop; ESP32 sends sensor data to broker over TLS/mTLS |
| **Power Input (ESP32)** | 5V USB or 3.3V direct supply | USB hub preferred for multiple nodes; 3.3V regulator alternative |
| **Power Requirements** | ~80–200 mA per node during active MQTT publish | Powered hub rated ≥2A for 2–3 simultaneous nodes |

## 3. Wiring Diagram (ESP32 ↔ DHT22)

```
Breadboard Layout:
─────────────────────────────────────────────

ESP32 (3.3V)         DHT22 (Breakout or bare)
───────────────────────────────────────────────
3.3V ───┐          VCC (pin 1) ← Power
        └──────────────────────────┘
        
GND (-)             GND (pin 4)
   │                     │
   └─────────────────────┘
        
GPIO4 (D4)  ───┬──4.7kΩ resistor ──→ 3.3V (pull-up)
            │
            └──── DATA (pin 2)

Notes:
- Pin 1: VCC (3.3V)
- Pin 2: DATA (GPIO4 via pull-up)
- Pin 3: Not connected (usually, or NC)
- Pin 4: GND

Optional alternative GPIO pins: GPIO5, GPIO12, GPIO13, GPIO14, GPIO15
```

## 5. Optional Extensions (Week 8+)

### MQ-135 Air Quality Sensor
- **Purpose:** Detect airborne chemical hazards (VOCs, ammonia, etc.)
- **Components:** MQ-135 breakout board, resistor divider for analog reading
- **Cost:** 600–900 LKR
- **Integration:** GPIO34 (ADC) on ESP32 → fetch gas ppm from breakout
- **Trigger:** Agent C publishes additional `gas_ppm` field in MQTT JSON
- **Status:** Not required for MVP; adds Week 8+ feature

### RC522 RFID Reader + Tags
- **Purpose:** Identify chemical containers or storage zones
- **Components:** RC522 breakout, SPI cable header, RFID tags/cards
- **Cost:** 1,200–1,800 LKR
- **Integration:** SPI (CS, MOSI, MISO, SCK, RST) on ESP32
- **Trigger:** Agent C publishes `container_id` field in MQTT JSON
- **Status:** Not required for MVP; adds Week 8+ feature

## 9. Power Calculations

### Single Node (1 × ESP32 + 1 × DHT22)
- ESP32 idle: ~25 mA  
- ESP32 WiFi/MQTT: ~80–120 mA  
- DHT22: ~1–5 mA  
- **Total: ~90–130 mA per node**

### Multi-Node Setup (2–3 nodes via USB hub)
- 2 nodes: ~180–260 mA  
- 3 nodes: ~270–390 mA  
- **USB hub rating:** ≥2A (2,000 mA) provides 7–11× headroom

### Alternative: Direct 3.3V Supply
- Requires 3.3V LDO regulator rated for ≥500 mA
- Example: AMS1117-3.3 (cost ~150–250 LKR)
- Input: 5V external PSU
- Output: 3.3V to breadboard rail

## 10. Common Pitfalls

| Issue | Cause | Solution |
|---|---|---|
| "COM port not found" | USB cable is charge-only | Try different Micro USB cable or verify with device manager |
| DHT22 reads erratic/NaN | Missing pull-up resistor or loose connection | Add 4.7kΩ pull-up to DATA line or check breadboard seating |
| ESP32 won't upload | Wrong board selected in PlatformIO | Verify `platform = espressif32` and `board = esp32doit-devkit-v1` in `platformio.ini` |
| Can't connect to WiFi | SSID/password wrong or 5 GHz network | Verify 2.4 GHz network, double-check credentials |
| MQTT connection fails | Mosquitto not running or TLS cert missing | Run `docker compose up -d` and verify `firmware/certs/` exists |
