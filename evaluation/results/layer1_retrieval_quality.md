## Summary by configuration

The latency column is the point of index elimination existing at all -- it should trade a little relevance for a lot of speed relative to `+ TF-IDF` (Lab 06A). Boolean-only's P@5/R@10 numbers are computed over an *unordered* set (Boolean retrieval has no ranking) -- treat them as a baseline for what ranking (TF-IDF) fixes, not a fully comparable ranked score.
